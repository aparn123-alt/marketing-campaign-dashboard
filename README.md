# Marketing Campaign Performance Dashboard
   
   
   ## Overview
   Brief description of what the dashboard tracks and key insights.
   
   ## Tools Used
   Power BI, DAX
   
   ## Key Insights
   - SEO campaigns significantly outperform paid channels on ROI

   - Overall funnel conversion rate: 15.3%
